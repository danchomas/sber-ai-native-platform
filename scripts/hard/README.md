# Сложные вопросы уровня финала

`make eval-hard` задаёт вопросы из `questions.tsv` через API поднятого стенда,
каждый в новой сессии и несколько раз, и сверяет ответы с ожиданиями:
вердикт в начале ответа, обязательные упоминания, запрещённые доводы.
Сбои связи с моделью считаются отдельно.

```
make eval-hard                 # все вопросы по 3 раза
make eval-hard RUNS=5 ONLY=q2  # один вопрос 5 раз
```

Ответы и сводка — в `scripts/hard/out/<время>/` (в git не входят).

- `q1`, `q2` — примеры вопросов финала;
- `h1`–`h10` — вопросы того же типа, на которых настраивался агент;
- `n1`–`n8` — контрольные: под них агент не настраивался, по ним видно,
  что правки работают в общем виде, а не под конкретный вопрос.

Эталоны посчитаны запросами из `reference/`. Имена таблиц в них — со стенда
разработки, суффикс у другого стенда свой:
`select name, table_name from datasets;`.
